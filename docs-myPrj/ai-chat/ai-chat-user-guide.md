# AI Чат-бот в карточке сделки — Руководство пользователя

## Назначение

AI-ассистент позволяет задавать вопросы по документам сделки прямо из карточки. Бот читает прикреплённые файлы (PDF, Word, Excel, TXT, CSV) и отвечает на вопросы по их содержимому.

---

## Как открыть чат

1. Откройте карточку любой сделки (например, `/deals/5`).
2. В правом нижнем углу экрана находится круглая кнопка с иконкой чата.
3. Нажмите на неё — откроется панель AI-ассистента.

---

## Как задать вопрос

1. Введите вопрос в текстовое поле внизу панели чата.
2. Нажмите кнопку **Отправить** или клавишу **Enter**.
3. Ответ AI будет появляться в реальном времени (посимвольно).
4. Для переноса строки в сообщении используйте **Shift + Enter**.

### Примеры вопросов

- «Какая сумма договора указана в документах?»
- «Перечисли основные условия контракта»
- «Есть ли в документах упоминание штрафных санкций?»
- «Сравни условия оплаты в разных документах»
- «Какие риски ты видишь в этой сделке?»

---

## Какие документы анализирует бот

AI-ассистент автоматически читает **все документы**, прикреплённые к текущей сделке. Поддерживаемые форматы:

| Формат | Расширения |
|--------|-----------|
| PDF | `.pdf` |
| Microsoft Word | `.docx` |
| Microsoft Excel | `.xlsx`, `.xls` |
| Текстовые файлы | `.txt` |
| CSV-таблицы | `.csv` |

> **Важно:** Если к сделке не прикреплено ни одного документа, бот сможет отвечать только на основе данных карточки сделки (клиент, сумма, статус и т.д.).

---

## Контекст разговора

- Бот помнит все сообщения **в рамках текущей сессии** (пока вы не закроете или не перезагрузите страницу).
- Вы можете задавать уточняющие вопросы — бот учитывает предыдущие сообщения.
- Для начала нового разговора нажмите кнопку **корзина** в заголовке чата.

---

## Кто может пользоваться чатом

AI-ассистент доступен:
- **Участникам сделки** (инициатор, согласующие, наблюдатели)
- **Администраторам** системы

Если вы не являетесь участником сделки и не администратор, при попытке отправить вопрос появится ошибка «Нет доступа к этой сделке».

---

## Ограничения

| Параметр | Значение |
|----------|----------|
| Максимальный размер текста из одного файла | 50 000 символов |
| Максимальный общий объём текста из всех файлов | 150 000 символов |
| Лимит запросов | 20 в минуту на пользователя |

Если документ слишком большой, бот проанализирует первые 50 000 символов и укажет, что текст был обрезан.

---

## Возможные ошибки

| Сообщение | Причина | Что делать |
|-----------|---------|------------|
| «AI-сервис не настроен» | Не указан API-ключ в настройках сервера | Обратиться к администратору |
| «Недостаточно средств на балансе Anthropic API» | Закончились кредиты на API | Администратору нужно пополнить баланс на console.anthropic.com |
| «Нет доступа к этой сделке» | Вы не участник сделки | Попросите администратора добавить вас в участники |
| «Слишком много запросов» | Превышен лимит 20 запросов/мин | Подождите минуту |
| «Ошибка соединения» | Проблемы с сетью | Проверьте интернет-соединение и попробуйте снова |

---

## Советы по использованию

1. **Будьте конкретны** — вместо «Расскажи о документе» спросите «Какой срок действия договора?»
2. **Задавайте уточняющие вопросы** — бот помнит контекст разговора, можно продолжать диалог.
3. **Загрузите документы до начала чата** — бот анализирует только те документы, которые уже прикреплены к сделке.
4. **Используйте для сравнения** — бот может сравнивать данные из нескольких документов одной сделки.

## Для администратора: настройка AI-сервиса

### Получение API-ключа

1. Зайти на https://console.anthropic.com/
2. Зарегистрироваться или войти
3. Раздел **API Keys** → **Create Key**
4. Скопировать ключ (начинается с `sk-ant-`)

### Настройка сервера

В файле `.env` указать:

```
ANTHROPIC_API_KEY=sk-ant-ваш-ключ
ANTHROPIC_MODEL=claude-sonnet-4-20250514
```

Параметр `ANTHROPIC_MODEL` можно изменить на другую модель Claude при необходимости.

После изменения `.env` перезапустить сервис:

```bash
sudo systemctl restart korus-spr
```

### Пополнение баланса

Баланс API пополняется на https://console.anthropic.com/settings/billing (минимум $5). Это **отдельный** баланс от подписки Claude — они не связаны.
